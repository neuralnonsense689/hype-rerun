2025's coding-agent game tests, rerun on Haiku 5.5 and GPT-6.1 Terra

October 2026. Two games that 2025's top models built as coding agents, given again with the same prompts to two of today's cheap models.

A Counter-Strike-style shooter in Three.js

In November 2025 a developer at a database startup gave GPT-5.1-Codex-Max, Claude Opus 4.5 and Gemini 3 Pro the same series of prompts to build a browser shooter, then made it multiplayer. The post reached 287 points on Hacker News. I gave Haiku 5.5 and GPT-6.1 Terra the first four prompts, word for word and in order, starting from the same empty Next.js template the originals started from.

The four prompts: a first-person map with a crosshair and enemies you can shoot; enemies that look like people; a gun in view that kicks back when you shoot; chiptune shot sounds and death animations. The clip shows stage 3: first Haiku, then Terra, each next to Opus 4.5, which the post judged best of the three on visuals. The Opus clip is the post's four-second GIF of the gun, so it shows less of the map than the new games, which are played by a script.

  • Haiku made a separate Vite project next to the Next.js app. It checked the game logic in Node, and said after each stage that it could not see the game run in its sandbox.

Minesweeper, judged blind

In December 2025 Ars Technica gave four coding agents one short prompt: a full-featured web Minesweeper with sound effects that replicates the Windows game, adds a surprise feature, and works on touchscreens. Their games editor scored the results without knowing which agent made which: Codex (GPT-5) 9/10, Claude Code with Opus 4.5 7/10, Mistral Vibe 4/10, and Gemini CLI did not produce a working game. I gave the same prompt to Haiku 5.5 and Terra.

The clip shows the Ars winner, Codex, next to Haiku and then Terra, cropped to the board. Each board gets the same two clicks: the first square, which Windows Minesweeper never makes a mine, and one flag.

How this was run

  • Haiku ran in Claude Code (claude-haiku-5-5, effort high). Terra ran in Codex CLI (gpt-6.1-terra, reasoning high). Neither used a stronger model as a helper.
  • The original agents ran in their own terminal apps, with the tools around each model set by its vendor. So the tools differ, not only the models.
  • One run per model. That's enough to see what happened, not to rank models.
  • Both tests have been public for months, so the new models may have seen them during training.
  • Terra ran in the Codex sandbox and Haiku in the Claude Code sandbox. Neither had a browser tool or web search.
  • My first Haiku Minesweeper run ($0.07, 6 minutes) also had my personal Claude Code rules file loaded, so I reran it without that file. The table shows the rerun.
  • Costs are the tokens each run used at the provider's API list price. I ran them on subscriptions, so nothing was charged. The original posts don't give costs, so there's no price comparison.
