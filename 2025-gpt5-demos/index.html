2025 GPT-5 demos, rerun on Haiku 5.5

October 2026. Three demos people shared around the GPT-5 launch, rerun with the same prompts on Claude Haiku 5.5 at two effort levels.

3D aquarium

On GPT-5 launch day (Aug 2025), a developer tested it in Cursor with a 3D aquarium plan inside a Next.js project that already had a Space Invaders page. Haiku 5.5 got the same plan, word for word, in a similar Next.js project with a small Space Invaders page.

3D octopus

From a GPT-5 vs Sonnet 4 comparison (Sep 2025) by the maker of Octocode, a code search tool. The prompt asks for research with the Octocode MCP; the GPT-5 result on the left is the run without that tool. Haiku got the same prompt, also without search tools.

Haiku high, live Haiku xhigh, live Original comparison page by Guy Bary, with the prompt

More effort did worse here. On xhigh, Haiku named a shader variable patch, which is a reserved word in GLSL, so the sea floor never compiles.

Then one follow-up to that xhigh run: open the page in a browser with Playwright MCP, check the console, and fix only what causes errors. Haiku found the reserved word and renamed it to sandPatch, a two-line change. It took 36 seconds and about one cent. I don't know whether the GPT-5 run got a check like this, so both versions are here.

How this was run

  • One run per demo and effort level, no retries, and the results are shown as they came out.
  • Claude Code in headless mode with model claude-haiku-5-5. No follow-up prompts from a human, except the one browser check on the octopus xhigh run. The model could read and edit its own files. For the aquarium it could also run npm commands, as the original ran inside an IDE agent.
  • No browser and no web search, so the model never saw its own output render. The exception is that octopus follow-up, which used Playwright MCP 0.0.83 in a headless browser.
  • Costs are API list prices for the tokens each run used, as Claude Code reports them.
  • The original GPT-5 costs were not published, so there is no price comparison here.
  • This is a rerun of public demos, not a benchmark.
  • For hosting, the two aquarium apps were built as static files (a next.config.ts with a static export setting was added). Their code is otherwise unchanged.
