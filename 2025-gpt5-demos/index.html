2025 GPT-5 demos, rerun on Haiku 5.5

October 2026. Three demos people shared around the GPT-5 launch, rerun with the same prompts on Claude Haiku 5.5 at two effort levels. Added later: the same prompts on GPT-6.1 Terra.

3D aquarium

On GPT-5 launch day (Aug 2025), a developer tested it in Cursor with a 3D aquarium plan inside a Next.js project that already had a Space Invaders page. Haiku 5.5 got the same plan, word for word, in a similar Next.js project with a small Space Invaders page.

3D octopus

From a GPT-5 vs Sonnet 4 comparison (Sep 2025) by the maker of Octocode, a code search tool. The prompt asks for research with the Octocode MCP; the GPT-5 result on the left is the run without that tool. Haiku got the same prompt, also without search tools.

Haiku high, live Haiku xhigh, live Original comparison page by Guy Bary, with the prompt

More effort did worse here. On xhigh, Haiku named a shader variable patch, which is a reserved word in GLSL, so the sea floor never compiles.

Then one follow-up to that xhigh run: open the page in a browser with Playwright MCP, check the console, and fix only what causes errors. Haiku found the reserved word and renamed it to sandPatch, a two-line change. It took 36 seconds and about one cent. I don't know whether the GPT-5 run got a check like this, so both versions are here.

Added later: the same prompts on GPT-6.1 Terra

Added October 30, 2026, after the post went up.

With only Haiku, you can't tell whether Haiku is special or whether cheap models in general have caught up. So I gave the same three prompts to OpenAI's GPT-6.1 Terra on high reasoning effort. Each one ran once, with no follow-ups. Terra's list price is $1 per million input tokens and $5 per million output tokens, ten times Haiku 5.5's.

Terra replaced the Space Invaders page with the aquarium, which the plan allows ("instead of/alongside"). It has all five species, plants, bubbles and a species guide. It skipped the glass tank walls the plan asks for. Haiku built the tank and kept a switch to Space Invaders.

Terra's octopus has a moving water surface but no sea floor, rocks or seaweed, and it drifts near the middle instead of swimming across. Haiku on high added more of the scene. Terra wrote a comment in the file saying Octocode MCP wasn't available, then went ahead without it, as Haiku did.

Terra's solar system has a planet list, an info card for the selected planet, and speed and zoom controls.

Terra high aquarium, live Terra high octopus, live Terra high solar system, live

Costs and times for every run are in the table below. Terra's three runs came to $0.19, and Haiku's three high runs to $0.21. The costs are close even though Terra costs ten times as much per token, because Terra wrote far fewer tokens. On the octopus it produced 7,702 output tokens, while Haiku produced 88,716, most of them thinking. Times are wall-clock times on each company's service, so treat them as rough.

How the Terra runs differ from the Haiku runs:

  • Terra ran in the Codex CLI (0.165.0, codex exec), which always gives the model a shell. So on the octopus and solar system, Terra could run commands. It wrote the files from the shell and ran a JavaScript syntax check with Node. Haiku could only read and write files there. On the aquarium, both could run commands.
  • Neither could open a browser, so neither saw its page render. Web search, my own Codex settings, skills, plugins and image generation were turned off.
  • Network access was off for the octopus and solar system, and on for the aquarium so npm could install packages. Terra's first npm install failed on a cache permission error in the Codex sandbox. Terra retried with a temporary cache folder on its own.
  • Costs are the tokens each run used, priced at OpenAI's standard API rates ($1.00 input, $0.05 cached input, $5.00 output per million tokens). I ran it on a Codex subscription, so no money was actually charged.
  • Only one effort level (high) and one run each, so this shows what one try looked like, not which model is better.
  • The Terra aquarium was built as static files for hosting, the same way as Haiku's.

How this was run

  • One run per demo and effort level, no retries, and the results are shown as they came out.
  • Claude Code in headless mode with model claude-haiku-5-5. No follow-up prompts from a human, except the one browser check on the octopus xhigh run. The model could read and edit its own files. For the aquarium it could also run npm commands, as the original ran inside an IDE agent.
  • No browser and no web search, so the model never saw its own output render. The exception is that octopus follow-up, which used Playwright MCP 0.0.83 in a headless browser.
  • Costs are API list prices for the tokens each run used, as Claude Code reports them.
  • The original GPT-5 costs were not published, so there is no price comparison here.
  • This is a rerun of public demos, not a benchmark.
  • For hosting, the two aquarium apps were built as static files (a next.config.ts with a static export setting was added). Their code is otherwise unchanged.
